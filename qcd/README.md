## 主要结果

- **程序验证**：N=7,9 与稠密直接解对照，阈值 1e-4 → 1e-10 时
  ε∞ 从 2.3e-5 降到 1.1e-11，满足 ε∞ ≤ ||A⁻¹||∞ ||r||∞。
- **基准算例**：N=31, m=0.5, ω=1.5，K=33，||r||∞=3.89e-7，
  u_max=0.376855（源点）。
- **响应范围**：N=63，m=0.2/0.5/1.0 的尾段衰减长度
  ξ=4.26/1.74/0.90 格距，mξ≈0.85–0.90。
- **ω 扫描**：N=63, m=0.5 最优平台 ω≈1.41–1.43，K=30；
  Gauss–Seidel K=68，减少 55.9%（S=2.27）。
- **理论对照**：ω_exp=1.684/1.418/1.174，ω_th=1.741/1.491/1.249；
  阈值从 1e-6 收紧到 1e-12 时，经验最优从 1.41 移到 1.47。
