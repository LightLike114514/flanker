## 为什么这么精简

上一次提交的完整包中，`results/results.json` 约 9.4 万字符，加上四个代码文件后
触发平台的 120000 字符审计上限（报告为 121898 字符）。本包移除了可由代码重新生成的
中间数据、插图和排版脚本，只保留报告 PDF 与复现数值结果所需的两个核心文件；
文本审计内容约 4.3 万字符，留有充足余量。

需要重新生成数据时运行：

```powershell
python code/experiments.py
```

## 主要结果

- 验证：`N=7,9` 与稠密直接解对照，阈值 `1e-4 → 1e-10` 时
  `ε∞ = 2.3e-5 → 1.1e-11`，满足 `ε∞ ≤ ||A⁻¹||∞ ||r||∞`。
- 基准：`N=31, m=0.5, ω=1.5`，`K=33`，`||r||∞=3.89e-7`，
  `u_max=0.376855`（源点）。
- 响应范围：`N=63`，`m=0.2/0.5/1.0` 的尾段衰减长度
  `ξ = 4.26/1.74/0.90` 格距，`mξ ≈ 0.85–0.90`。
- `ω` 扫描：`N=63, m=0.5` 最优平台约 `1.41–1.43`，`K=30`；
  Gauss–Seidel `K=68`，减少 `55.9%`（`S=2.27`）。
- 理论对照：`ω_exp = 1.684/1.418/1.174` 低于
  `ω_th = 1.741/1.491/1.249`；阈值收紧后经验最优从 `1.41` 移到 `1.47`。

> 注意：本题是标量格点点源模型，**不是格点 QCD 模拟**；报告第 8.2 节有明确说明。
