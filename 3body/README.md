# 三体问题作业：平面等质量三体的有界运动模式

本目录完成《计算物理》作业“《三体》中的稳定运动模式”。包含可复现程序、结果数据、图表、
中文报告和自检脚本。

## 快速运行

```powershell
python -m pip install -r requirements.txt
python run_experiments.py      # 约 5–8 分钟，生成 results/
python make_figures.py         # 生成 figures/*.png
python test_three_body.py      # 8 个断言测试

# 编译 LaTeX 报告（跑两遍以生成目录/交叉引用）
cd latex
xelatex 三体问题作业报告.tex
xelatex 三体问题作业报告.tex
```

依赖：Python 3.12+、numpy、matplotlib；`make_report.py` 另需 python-docx（DOCX 备用版）。

## 结果概览

四种模式（G = m = 1，0 ≤ t ≤ 50，预警阈值 0.05）：

| 模式 | 结构 | t_end | d_min | d_max | E₀ | 对 10⁻⁴ 扰动的响应 |
|---|---|---|---|---|---|---|
| A | Lagrange 等边三角形（解析解） | 50 | 1.0000 | 1.0000 | −1.500000 | 指数失稳，t≈15.55 瓦解 |
| B | 8 字形舞蹈 | 50 | 0.6905 | 2.0000 | −1.287142 | 有界，δ≤6.3×10⁻³ |
| C | 飞蛾 I（moth I） | 50 | 0.0794 | 2.1601 | −1.382296 | 有界但边缘，δ≤1.2×10⁻² |
| D | 层级三体（紧密双星 + 远方第三体） | 50 | 0.3993 | 4.2000 | −1.501253 | 鲁棒，δ≤7.6×10⁻⁴ |

- 模式 A：ω = √3，T = 3.6276，E = −1.5，L = √3；线性增长率 λ = 1.2247。
  双精度误差约 10⁻¹⁶，被不稳定模式放大，t≈30 后偏离解析解，因此 A 的轨迹用解析解给出。
- 模式 B：题目给定初值，周期约 6.3259，50 时间内约 7.9 个周期。
- 模式 C：Šuvakov–Dmitrašinović 对称族的 moth I；15 个已发表候选中唯一满足
  0.05 ≤ d_min 且 d_max < 10 的轨道。
- 模式 D：自行构造的双星 + 第三体层级构型；双星周期约 1.12，外轨道周期约 29.0，
  时间尺度分离带来鲁棒性。

## 数值要点

1. **引力与能量**：`accelerations` 用 `diff / r³` 向量化；`total_energy` 计算
   `T + U`。t=0 的 Lagrange 力平衡残差约 1e-15。
2. **近距离停止**：每步检查 `min(d12,d13,d23) < 0.05`，命中即停止并记录时间；
   同时限制最大半径，避免逃逸轨道无限积分。
3. **能量 ≠ 轨迹精度**：模式 A 的 RK4 能量误差只有 3.9×10⁻⁶，但 t=30 时轨迹已偏离
   解析解 2.09；不稳定模式会把相位误差指数放大。
4. **步长敏感性**：8 字形的 RK4 位置差约 1.2×10⁻⁹；飞蛾 I 在近距离交会处对步长敏感，
   Δt=0.002 与 0.001 的最大位置差 0.042、最大速度差 1.82、d_min 差 0.029，
   所以扰动实验使用 DP45（rtol=1e-13），不能只用固定步长 RK4。
5. **模式 A 的双精度极限**：λ≈1.2247，要在 t=50 内保持 O(1) 以下需要约 27 位
   十进制有效数字；双精度（~16 位）不够。因此 A 的轨迹/距离用解析解，数值积分只用于
   展示“舍入误差如何触发物理不稳定”。

## AI 使用记录（摘要）

AI 用于生成代码初稿、检索候选初值和整理报告。所有数值由本地程序复算，AI 建议均独立核验：

- AI 推荐 butterfly I：独立积分得 d_min = 0.0110 < 0.05，**剔除**；改用 moth I。
- AI 建议双精度直接模拟模式 A：与解析解对比发现 t≈30 后偏差 O(1)，线性分析确认
  λ = 1.2247，**改为解析解 + 数值精度反例**。
- AI 生成的积分器/绘图代码：用解析解残差、能量守恒、步长收敛和 8 个断言测试核验。

详见报告第九节和 `report/三体问题作业报告.pdf`。

## 备注

- `run_experiments.py` 使用固定初值，无随机性；不同平台的 BLAS/浮点差异只影响
  10⁻¹² 量级的数值。
- 报告中的数字来自当前 `results/summary.json`；若重新运行实验，数字会有微小变化，
  但结论不变。最终报告只保留 PDF，DOCX 生成脚本仅作备用。
